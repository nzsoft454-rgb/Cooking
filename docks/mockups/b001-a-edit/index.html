B-001-a「食材の編集」UI 案 — 全 8 パターン

IngredientEditScreen · Design D1 · カレンダー UI なし（チップ / スライダー / 直接入力）

方針： スマホ画面のため月間カレンダーは使わない。期限は 相対日チップ（+3日 / 1週間 等）＋必要時のみ 日付テキスト入力。
A カード B リスト C ビジュアル D 分割 E ステッパー F シート G カウント H 拡大カード

案 A：セクションカード型

ヒーロー + 期限チップ + 残量スライダー

  • 情報の塊が分かりやすい
  • 手入力を減らせる

案 B：設定リスト型

iOS Settings 風の行 UI

  • 1 画面に収まりやすい
  • 実装コスト低め

案 C：ビジュアル操作型 ★

25/50/75/100% + 期限チップ

  • モバイル向けで最も直感的
  • 0〜1 を UI から隠せる

案 D：上下分割型

上半分で食材、下半分で残量リング + 期限チップ

  • 編集対象が常に見える

案 E：3 ステップ型

名前 → 期限（チップ）→ 残量

  • 1 画面 1 目的
  • 初めてのユーザー向け

案 F：ボトムシート型

一覧を薄く残して下から編集

  • 一覧との文脈を保つ
  • スワイプで閉じやすい

案 G：期限カウントダウン型

「あと N 日」を主役に

  • 期限管理が主目的のとき有効

案 H：カード拡大型

B-001 のカードをそのまま拡大

  • 一覧からの遷移が自然
