# 1. アプリケーション概要
* **アプリ名**: スマート食材管理＆AIレシピ生成アプリ（仮）
* **ターゲット**: スマートフォンネイティブアプリ（Android対応）
* **コンセプト**: 「冷蔵庫の中身をスマホのカメラで撮るだけ」で在庫を自動登録し、賞味期限の迫った食材からGemini APIが最適なレシピを自動提案する、スマートな食材・調理管理モバイルアプリ。
* **技術スタック**:
  - フロントエンド: React Native (TypeScript, Expo SDK, React Navigation, Tamagui or NativeWind)
  - バックエンド: APIサーバー（Laravel / PHP ＋ MySQL などを想定）
  - 外部API: Google Gemini API (画像解析 & レシピ生成)
